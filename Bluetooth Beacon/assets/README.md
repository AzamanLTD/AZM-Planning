# Azaman Presence concept assets

The six SVGs in this directory are original vector concept illustrations authored for this planning package. They are not technical drawings, surveyed deployments, photographs of installed devices, manufacturer schematics, safety approvals or evidence of implementation.

| File | Description |
|---|---|
| 01_azaman_presence_overview.svg | Physical merchant storefront connected via the customer's phone |
| 02_standalone_architecture.svg | Beacon → phone → Azaman platform → storefront; no merchant network required for basic discovery |
| 03_multi_store_selection.svg | Customer choice when several nearby businesses are detected |
| 04_daily_device_verification.svg | Worker tests and customer observations shown as separate evidence |
| 05_five_vertical_use_cases.svg | Retail, restaurants, hotels, fuel and transit experiences |
| 06_fuel_station_flow.svg | Station discovery, explicit pump selection and separate safety/payment controls |

Each graphic uses a 16:9 vector canvas and can be revised without raster re-export. All are illustrative; supplier specifications, permissions, site layouts and production functionality require separate evidence and approval.
